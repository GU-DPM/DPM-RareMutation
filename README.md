# DPM-RareMutation
Code and data associated with the manuscript:  
**Probability Distribution for Rare Neutral Mutations in Cancers and Application to Dynamic Precision Medicine of Cancer**  
Preprint available on bioRxiv: https://www.biorxiv.org/content/10.1101/2025.10.10.681641v2
## Overview
This repository contains the code and data used to reproduce the analyses and results presented in the manuscript.
The study investigates probability distributions for rare neutral mutations in cancer and evaluates their application to Dynamic Precision Medicine (DPM) of cancer.
The repository is organized as follows:
- 'code/' - Source code for the analyses and simulations
- 'data/' - Data used in the simulations
- 'figures/' - Figures used in the manuscript.

The analyses were performed using Python. Script for reproducing the analyses and figures in the manuscript are provided in the 'code/' directory.
